# Rumah gaya kota, biome Hutan

Format mengikuti paket kota: lantai bawah batu/plester, lantai atas rangka kayu (half-timber) yang sedikit menjorok,
atap genteng berwarna dengan jendela atap dan cerobong, jendela berdaun dengan kotak bunga, kanopi belang,
papan gantung di sisi kanan. Pintu 26x44 px, titik pijak = tengah tepi bawah (pivot di JSON).

Daftar (akhiran _hutan): rumah_petani, rumah_warga1-3, rumah_penjaga, rumah_pandai_besi (lengkung tempa), rumah_pustakawan,
rumah_pedagang, rumah_tukang_roti, rumah_penebang_kayu, rumah_pemburu, kedai, rumah_pencuri, rumah_tabib,
rumah_pendeta (gereja bermenara), rumah_bangsawan, barak, depot_gudang, depot_kantor_pertukaran.
Data pintu dan titik asap cerobong: data_rumah_gaya_kota_hutan.json
